A browser-based solver for the [24 card game](https://en.wikipedia.org/wiki/24_(puzzle)). Enter any four integers and instantly see every valid expression — using +, −, ×, ÷ — that evaluates to 24.

Built with pure JavaScript using exact rational arithmetic, so edge cases like `8 / (3 - 8/3) = 24` are handled correctly without floating-point errors.
